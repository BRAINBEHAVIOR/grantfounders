## Dicas de Uso e Considerações Importantes

### Para Máxima Efetividade dos Prompts:

1. **Especificação de Dispositivos:**
   - Sempre mencione "MacBook Pro 16-inch" e "iPhone 14 Pro" para consistência
   - Solicite mockups "ultra-realísticos" para apresentações profissionais

2. **Consistência Visual:**
   - Mantenha a paleta de cores em todos os prompts: Navy #081B33, Gold #FFD700, White #FFFFFF
   - Enfatize o branding "Powered by Abasensor™" em todas as páginas

3. **Adaptações Mobile:**
   - Sempre solicite versões responsivas específicas
   - Enfatize interações touch-optimized para mobile

4. **Elementos de Confiança:**
   - Inclua badges de segurança governamental (PCI, SOC2, FedRAMP Ready)
   - Mantenha o tom profissional e federal-grade

### Variações Recomendadas:

**Para Apresentações Executivas:**
- Adicione "executive presentation style" ao prompt
- Solicite "boardroom-ready mockups"

**Para Demonstrações Técnicas:**
- Enfatize "developer-focused" na documentação da API
- Adicione "technical accuracy" aos dashboards

**Para Propostas Governamentais:**
